# Human Telly

在 Scaffold 的 `Mode` 中选择 `Human Telly`。需要自动连续起跳时启用 `Auto Jump`，否则由玩家跳跃。

- `Telly Tick`：起跳后静默转向放置面的 tick 数，仅影响瞄准，不控制点击。
- `Human Turn Speed`：静默转头速度上限，默认 65 度/tick。
- `Human Noise`：低频漂移、多频抖动与末端修正幅度，默认 1.2；设 0 关闭角度噪声。
- `Human CPS`：开启本模式期间持续点击的平均频率，默认 9；按下时长和点击间隔有小幅变化。相位补偿避免 20 TPS 的取整误差让 16 CPS 退化成 10 CPS。卡顿不会补发积压点击。
- 点击与瞄准分离：普通行进和瞄准时持续点击；确认放置成功后立即进入回转阶段并暂停点击，回到行进方向后恢复。其他阶段即使无目标、准星未对齐、点击失败或耗尽方块也持续点击；本模式忽略旧 `Delay`，缺少方块不再自动关模块。
- 相机仍由玩家鼠标控制；独立的静默 yaw/pitch 按帧带噪声平滑，供移动包及原版射线使用。第三人称模型可显示静默转头，第一人称镜头不会被拉走。
- 移动输入按相机方向转换为静默朝向下最近的普通 WASD 组合，仅修正一次。
- 使用当前绑定的 Use 键（默认鼠标右键），执行按下、短暂保持、松开；由原版 `handleKeybinds → startUseItem` 处理，不直接调用 `useItemOn`，不伪造命中位置，不额外发送挥手包。
- 不再用目标面、射线命中、可替换检查、手持方块或放置成功来决定是否点击。原版基于静默朝向执行实际射线，决定空点、实体/方块交互、距离限制、物品使用、放置与摆手；不伪造命中结果。
- 因为是真正的 Use 输入，可能打开箱子、操作门或使用手持物品，而不只是放方块。
- 本模式固定使用静默移动修正；`Delay`、`OnTick`、Omni Sprint、No Swing、Item Spoof 和 Tower 不参与本模式，相关设置隐藏且保留原值。
- 落地回转期间暂时停止合成的前进/侧移输入，角度恢复后再继续，可配合 Auto Jump 或玩家手动跳跃。切换模式、关闭模块、打开菜单、失焦、换世界、死亡或进入旁观状态时释放本模式持有的输入。玩家物理按住的 Use 键不会被主动松开。

## 能力边界

这是多通道、带状态的程序化运动控制器（粗瞄、制动、微调和四层相关噪声），**不是训练过的神经网络**。仓库没有真人轨迹训练集或模型权重，不声称与真人完全等价，也不保证任意地图和速度下都能连续搭桥。多个同时控制视角、冲刺或鼠标的模块可能冲突，实测时应先关闭它们。

## 自动检查

在项目目录运行 `gradlew.bat humanTellyCheck`。检查使用固定随机种子，不启动游戏、不发送输入或网络数据，覆盖多种帧率的收敛性、角速度上限、pitch 边界、灵敏度量化、yaw 跨界、WASD 换向、按下/释放、长期 CPS、CPS 修改、卡顿不补发及重置。

## 游戏内待验收（未执行）

1. 单人创造平坦地图，快捷栏放满整方块，选择本模式并启用 Auto Jump。检查相机不被自动转动、第三人称头部平滑转动、正常搭桥及移动方向。
2. 关闭 Auto Jump，手动跳跃；分别按 W、A/D、S 及斜向移动，检查静默转头时的移动方向与相机自由控制。
3. 在不同灵敏度、30/60/144 FPS、Noise 0/1.2/4 下检查角度连续性与放置成功率。
4. 对空气、地面无缺口、无可放置目标、物品用尽分别观察 Use 输入仍持续。设为 2/9/16 CPS 记录至少 30 秒输入次数；放置成功次数不等于点击次数。再检查实体遮挡、箱子、挖掘或使用物品由原版处理。
5. 点击期间打开菜单、切出窗口、关闭模块、切换模式、离开世界或死亡，检查 Use 不会卡住；手动按住右键时确认模块不会主动松开。
6. 把 Use 改绑为键盘键/其他鼠标键，检查该绑定的按下和松开；恢复 Normal/Telly Bridge/Legit 后检查原模式行为。
